PART 1: THE QUESTION
═══════════════════════════════════════════════════════════════════════════════

```
A Type II error occurs when
   (A) A true null hypothesis is rejected
   (B) A false null hypothesis is accepted
   (C) A false null hypothesis is rejected
   (D) A true null hypothesis is accepted
```

═══════════════════════════════════════════════════════════════════════════════
PART 2: THE FULL ANSWER, FROM ZERO (every step, nothing assumed)
═══════════════════════════════════════════════════════════════════════════════

ANSWER: (B).

TRAP: (A) is Type I. The two errors are mirror images: Type I rejects a TRUE H0; Type II
fails to reject a FALSE H0. Some source options say "accept", but write "fail to reject"
in your conclusion. Drill the table above until it is automatic.
