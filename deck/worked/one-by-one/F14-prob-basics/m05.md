PART 1: THE QUESTION
═══════════════════════════════════════════════════════════════════════════════

```
  Which inequality provides an upper bound on the probability that a random variable deviates from its mean?
      A) Bayes' theorem  B) Binomial theorem  C) Central Limit Theorem  D) Chebyshev's inequality
```

═══════════════════════════════════════════════════════════════════════════════
PART 2: THE ANSWER
═══════════════════════════════════════════════════════════════════════════════

```
  ANSWER: (D)

  WHY: Chebyshev bounds P(|X-mu| >= k sigma) <= 1/k^2.
```

```

     - direction swaps (P(B|A) vs P(A|B))

  read all four options, find the near-miss, pick the exact one.
```
