PART 1: THE QUESTION
═══════════════════════════════════════════════════════════════════════════════

```
  The expectation of a random variable represents its
      A) average value  B) maximum value  C) minimum value  D) most likely value
```

═══════════════════════════════════════════════════════════════════════════════
PART 2: THE ANSWER
═══════════════════════════════════════════════════════════════════════════════

```
  ANSWER: (A)

  WHY: expectation = probability-weighted average of the values.
```
