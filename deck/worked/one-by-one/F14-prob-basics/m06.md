PART 1: THE QUESTION
═══════════════════════════════════════════════════════════════════════════════

```
  The conditional probability of A given B is defined as
      A) P(B)/P(A)  B) P(A n B)/P(B)  C) P(A)+P(B)  D) P(A n B)/P(A)
```

═══════════════════════════════════════════════════════════════════════════════
PART 2: THE ANSWER
═══════════════════════════════════════════════════════════════════════════════

```
  ANSWER: (B)

  WHY: P(A|B) = P(A n B)/P(B); the given event sits in the denominator.
```
