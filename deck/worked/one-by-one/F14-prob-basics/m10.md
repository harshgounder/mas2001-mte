PART 1: THE QUESTION
═══════════════════════════════════════════════════════════════════════════════

```
  Chebyshev's inequality is applicable to
      A) only normal distributions  B) any distribution with finite mean and variance  C) only discrete distributions  D) only continuous distributions
```

═══════════════════════════════════════════════════════════════════════════════
PART 2: THE ANSWER
═══════════════════════════════════════════════════════════════════════════════

```
  ANSWER: (B)

  WHY: distribution-free: it needs only the mean and variance, no shape.
```

───────────────── THE CONCEPT BEHIND IT ─────────────────

```
  this MCQ tests a DEFINITION or a ONE-LINE FACT from the foundations.
  the wrong options are built from near-miss definitions:
     - direction swaps (P(B|A) vs P(A|B))
     - object swaps (probability vs distribution vs event)
     - scope swaps (only-normal vs any-distribution)
  read all four options, find the near-miss, pick the exact one.
```
