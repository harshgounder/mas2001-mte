## Uniform Distribution Example

**Example:** Uniform probability distribution over the range $2 \le x \le 6$:

$$f(x) = \frac{1}{6 - 2} = .25 \quad \text{for } 2 \le x \le 6$$

Figure: A probability density plot with vertical axis labeled f(x), horizontal axis labeled x. The vertical axis has a tick at .25. The horizontal axis has ticks at 2 and 6. A solid dark blue rectangle spans from x = 2 to x = 6 with height .25, representing a uniform distribution.

$$\mu = \frac{a + b}{2} = \frac{2 + 6}{2} = 4$$

$$\sigma^2 = \frac{(b - a)^2}{12} = \frac{(6 - 2)^2}{12} = 1.333$$
