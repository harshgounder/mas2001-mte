Discrete Random Variable: A discrete random variable is an rv whose possible values
either constitute a finite set or else can be listed in an infinite sequence in which there is a
first element, a second element, and so on (“countably” infinite).


Continuous Random Variable: A random variable is continuous if both of the
following apply:
1. Its set of possible values consists either of all numbers in a single interval on the
number line (possibly infinite in extent, e.g., from to ) or all numbers in a disjoint union
of such intervals (e.g., [0, 10] [20, 30]).
2. No possible value of the variable has positive probability, that is, P(X = c) = 0 for any
possible value c.

The importance of the cdf here, just as for discrete rv’s, is that probabilities of
various intervals can be computed from a formula for or table of F(x).

Proposition
Let X be a continuous rv with pdf f(x) and cdf F(x). Then for any number a,
                        P(X > a) = 1 – F(a)
and for any two numbers a and b with a < b,

                    P(a  X  b) = F(b) – F(a)

The following result is a consequence of the Fundamental Theorem of Calculus.

Proposition
If X is a continuous rv with pdf f(x) and cdf F(x), then at every x at which the
derivative F(x) exists,
                                  F(x) = f(x).
