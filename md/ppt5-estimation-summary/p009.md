## Unbiased Estimator
An estimator $\hat{\theta}$ is said to be unbiased for a parameter $\theta$ if
$E(\hat{\theta}) = \theta$

An estimator $\hat{\theta}$ is said to be unbiased for a parameter $\theta$ if
$$E(\hat{\theta}) = \theta$$

It neither overestimates nor underestimates the parameter on average.

$$\text{Bias}(\hat{\theta}) = E(\hat{\theta}) - \theta$$
