## Point Estimate vs Interval Estimate

**POINT ESTIMATE**
- One value
- Example:
- Estimated average response time = 210 ms
- $\checkmark$ Simple
- $\times$ Uncertainty not shown

**INTERVAL ESTIMATE**
- A range of plausible values
- Example:
- 95% CI = (204 ms, 216 ms)
- $\checkmark$ Shows uncertainty
- $\checkmark$ More informative
