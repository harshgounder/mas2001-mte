## Random Experiment

**Definition**
A **random experiment** is an experiment whose outcome cannot be predicted with certainty in advance, although all possible outcomes are known.

**Examples**
1. Tossing a coin
2. Rolling a die
3. Drawing a card from a deck of 52 cards
4. Selecting a student randomly from a class

**Illustration**

| Experiment | Possible Outcomes |
| :--- | :--- |
| Toss a coin | Head (H), Tail (T) |
| Roll a die | 1, 2, 3, 4, 5, 6 |
| Draw one card | Any one of the 52 cards |

**Note:** We know all possible outcomes, but we do not know which one will occur.
