## Random variable

**Example 1:** Let $X$ denote the random variable that is defined as the sum of two fair dice, then

$P[X = 2] = P[(1, 1)] = 1/36$

$P[X = 3] = P[(2, 1), (1, 2)] = 2/36$

$P[X = 4] = P[(2, 2), (3, 1), (1, 3)] = 3/36$

$P[X = 5] = P[(2, 3), (3, 2), (1, 4), (4, 1)] = 4/36$

$\dots$

$P[X = 11] = P[6, 5), (5, 6)] = 2/36$

$P[X = 12] = P[6, 6)] = 1/36$
