## Mutually Exclusive Events

**Definition**
Two events are **mutually exclusive** if they **cannot occur simultaneously**.
Mathematically,
$$A \cap B = \varnothing$$
That means there is **no common outcome**.

**Example 1**
Roll one die.
Event A:
Getting an even number
$$A = \{2, 4, 6\}$$
Event B:
Getting an odd number
$$B = \{1, 3, 5\}$$
Since
$$A \cap B = \varnothing$$
they are **mutually exclusive**.

**Example 2**
Toss one coin.
A = Head
B = Tail
A coin cannot show Head and Tail together.
Hence,
A and B are mutually exclusive.

**Counter Example**
Roll one die.
A = Even number
$$A = \{2, 4, 6\}$$
B = Prime number
$$B = \{2, 3, 5\}$$
Here,
$$A \cap B = \{2\}$$
Since they have a common outcome,
they are **NOT mutually exclusive**.
