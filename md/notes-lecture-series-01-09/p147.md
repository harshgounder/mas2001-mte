## Continuous Random Variables

a. $E(X) = \int_{\theta}^{\infty} x \cdot \frac{k\theta^k}{x^{k+1}} dx = k\theta^k \int_{\theta}^{\infty} \frac{1}{x^k} dx = \left[ \frac{k\theta^k x^{-k+1}}{-k+1} \right]_{\theta}^{\infty} = \frac{k\theta}{k-1}$

b. $E(X) = \infty$

c. $E(X^2) = k\theta^k \int_{\theta}^{\infty} \frac{1}{x^{k-1}} dx = \frac{k\theta^2}{k-2}$, so

$$Var(X) = \left( \frac{k\theta^2}{k-2} \right) - \left( \frac{k\theta}{k-1} \right)^2 = \frac{k\theta^2}{(k-2)(k-1)^2}$$

d. $Var(x) = \infty$, since $E(X^2) = \infty$.

e. $E(X^n) = k\theta^k \int_{\theta}^{\infty} x^{n-(k+1)} dx$, which will be finite if $n - (k+1) < -1$, i.e. if $n < k$.
