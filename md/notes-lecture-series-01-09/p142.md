## Continuous Random Variables

**EX.** The hospitalization period, in days for patients, following treatment for a certain type of kidney disorder is a random variable $Y = X + 4$, where $X$ has the density function

$$f(x) = \begin{cases} \frac{32}{(x+4)^3} & x > 0 \\ 0 & \text{elsewhere} \end{cases}$$

Find the average number of days that the person is hospitalized following treatment for this disorder.

**Ans.** $E(Y) = 8$ Days
