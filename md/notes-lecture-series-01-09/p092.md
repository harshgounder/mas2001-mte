## Expectation & Distribution parameters (cont...)

**Properties of mean:**
**Theorem:** If $X$ is a random variable and $c$ is a real number then, (a) $E[c] = c$ and (b) $E[cX] = cE[X]$.

**Proof:** 
$E[c] = \sum cf(x) = c \sum f(x) = c(1) = c.$
$E[cX] = \sum cxf(x) = c \sum xf(x) = cE[X].$
