## Random variable

Example 2: Suppose that our experiment consists of tossing two fair coins. Letting $Y$ denote the number of heads appearing, then $Y$ is a random variable taking on one of the values 0,1,2 with respective probabilities:
$$P[Y = 0] = P[(T, T)] = 1/4$$
$$P[Y = 1] = P[(H, T), (T, H)] = 2/4$$
$$P[Y = 2] = P[(H, H)] = 1/4$$
Of course
$$P[Y = 0] + P[Y = 1] + P[Y = 2] = 1$$
