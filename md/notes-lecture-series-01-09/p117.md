## Continuous Density

MANIPAL UNIVERSITY JAIPUR
Continuous Random Variables

Definition
**Continuous Density**
Let $X$ be a continuous random variable. A function $f(x)$ is called continuous density (probability density function i.e pdf ) if
(i) $f(x) \geq 0$
(ii) $\int_{-\infty}^{+\infty} f(x)dx = 1$
(iii) For any $a, b$ (real) with $-\infty < x < +\infty$ we have

$$P[a \leq x \leq b] = \int_{a}^{b} f(x)dx$$
