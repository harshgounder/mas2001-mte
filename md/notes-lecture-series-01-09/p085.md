## Discrete Random Variable

EX. Show that the cdf $F(x)$ is a nondecreasing function; that is, $x_1 < x_2$ implies that $F(x_1) \leq F(x_2)$. Under what condition will $F(x_1) = F(x_2)$?

If $x_1 < x_2, F(x_2) = P(X \leq x_2) = P(\{X \leq x_1\} \cup \{x_1 < X \leq x_2\})$
$$= P(X \leq x_1) + P(x_1 < X \leq x_2) \geq P(X \leq x_1) = F(x_1).$$

$F(x_1) = F(x_2)$ when $P(x_1 < X \leq x_2) = 0$.
