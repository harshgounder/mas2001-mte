A **random experiment** is an experiment whose outcome cannot be predicted with certainty in advance, although all possible outcomes are known.

## Mutually Exclusive Events

**Definition**
Two events are **mutually exclusive** if they **cannot occur simultaneously**.
Mathematically,
$$A \cap B = \varnothing$$
That means there is **no common outcome**.

**Example 1**
Roll one die.
Event A:
Getting an even number
$$A = \{2, 4, 6\}$$
Event B:
Getting an odd number
$$B = \{1, 3, 5\}$$
Since
$$A \cap B = \varnothing$$
they are **mutually exclusive**.

**Example 2**
Toss one coin.
A = Head
B = Tail
A coin cannot show Head and Tail together.
Hence,
A and B are mutually exclusive.

**Counter Example**
Roll one die.
A = Even number
$$A = \{2, 4, 6\}$$
B = Prime number
$$B = \{2, 3, 5\}$$
Here,
$$A \cap B = \{2\}$$
Since they have a common outcome,
they are **NOT mutually exclusive**.

## Mutually exclusive events

**Mutually exclusive events** are two or more events that cannot occur at the same time. For example, getting heads and tails in a coin toss or rolling a 2 and a 3 on a die.

If two events are mutually exclusive then

## Independent Events

**Definition**
Two events are **independent** if the occurrence of one event does **not affect** the occurrence of the other.
Mathematically,
$$P(A \cap B) = P(A) \times P(B)$$

**Example 1**
Toss a coin and roll a die.
Event A:
Getting Head $P(A) = \frac{1}{2}$
Event B:
Getting 6 $P(B) = \frac{1}{6}$
These two events do not affect each other.
Therefore,
$$P(A \cap B) = \frac{1}{2} \times \frac{1}{6} = \frac{1}{12}$$
Hence,
A and B are **independent events**.

**Example 2**
Draw one card, replace it, then draw another card.
Event A: First card is Ace
Event B: Second card is King
Since the first card is replaced, the second draw is unaffected.
Hence,
A and B are independent.

## Independence of events

**DEFINITION**
Two events $A$ and $B$ are **independent** if $P(A|B) = P(A)$ and are **dependent** otherwise.

Proposition: $A$ and $B$ are independent if and only if
$$P(A \cap B) = P(A) \cdot P(B)$$

**Independence of More Than Two Events**

**DEFINITION**
Events $A_1, \dots, A_n$ are **mutually independent** if for every $k (k = 2, 3, \dots, n)$ and every subset of indices $i_1, i_2, \dots, i_k$,
$$P(A_{i_1} \cap A_{i_2} \cap \dots \cap A_{i_k}) = P(A_{i_1}) \cdot P(A_{i_2}) \cdot \dots \cdot P(A_{i_k}).$$

$$= 1 - \frac{1}{15} - \frac{2}{5} = \frac{8}{15}.$$

    *   A certain college team has on its roster three centers, four guards, four forwards, and one individual (X) who can play either guard or forward. Solution.

(a) The number of lineups without $X$ equals $\binom{4}{2}\binom{4}{2}\binom{3}{1} = 108$.
The number of lineups with $X$ playing guard equals $\binom{4}{1}\binom{4}{2}\binom{3}{1} = 72$.
The number of lineups with $X$ playing forward equals $\binom{4}{2}\binom{4}{1}\binom{3}{1} = 72$.
Hence the number of lineups is $108 + 72 + 72 = 252$.

(b) The number of lineups with neither $X$ nor $Y$ equals $\binom{5}{2}\binom{5}{2}\binom{3}{1} = 300$.
The number of lineups with $X$ but not $Y$ equals $\binom{5}{1}\binom{5}{2}\binom{3}{1} + \binom{5}{2}\binom{5}{1}\binom{3}{1} = 300$.
The number of lineups with $Y$ but not $X$ equals $\binom{5}{2}\binom{5}{1}\binom{3}{1} + \binom{5}{1}\binom{5}{2}\binom{3}{1} = 300$.
The number of lineups with both $X$ and $Y$ equals $\binom{5}{1}\binom{5}{1}\binom{3}{1} + 2 \times \binom{5}{2}\binom{3}{1} = 135$.
Hence the number of lineups is $300 + 300 + 300 + 135 = 1035$.
Therefore the required probability equals $\frac{1035}{\binom{15}{5}} = \frac{1035}{3003}$.

## Conditional Probability

**DEFINITION** For any two events $A$ and $B$ with $P(B) > 0$, the conditional probability of $A$ given that $B$ has occurred is defined by
$$P(A | B) = \frac{P(A \cap B)}{P(B)}$$

Example 1.

Suppose that of all individuals buying a certain digital camera, 60% include an optional memory card in their purchase, 40% include an extra battery, and 30% include both a card and battery. Consider randomly selecting a buyer and let $A = \{\text{memory card purchased}\}$ and $B = \{\text{battery purchased}\}$. Then $P(A) = .60$, $P(B) = .40$, and $P(\text{both purchased}) = P(A \cap B) = .30$. Given that the selected individual purchased an extra battery, the probability that an optional card was also purchased is
$$P(A | B) = \frac{P(A \cap B)}{P(B)} = \frac{.30}{.40} = .75$$

That is, of all those purchasing an extra battery, 75% purchased an optional memory card. Similarly,
$$P(\text{battery} | \text{memory card}) = P(B | A) = \frac{P(A \cap B)}{P(A)} = \frac{.30}{.60} = .50$$
